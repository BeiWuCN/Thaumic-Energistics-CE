# 无线终端的饰品栏与按键

无线源质终端、无线奥术合成终端加入 `curios:curio` 物品标签，与 AE2 原生无线终端一致。Curios 未安装时不需要加载它的类，普通背包打开方式仍可使用。

两种终端分别注册打开按键，默认未绑定。在游戏“选项 → 控制 → 按键绑定”的 AE2 分类中设置“打开无线源质终端”和“打开无线奥术合成终端”。

注册复用 AE2 的 `HotkeyActions.register`，在模组构造阶段安装原生背包与饰品栏搜索动作，并使用对应的 `ItemMenuHostLocator` 打开宿主。匹配物品的谓词延迟读取注册对象，避免在物品注册完成前访问它；注册时机早于客户端按键定稿。频道、信号范围、链接、充电、升级槽及子菜单返回仍由无线终端原有实现负责。按键不改变 AE2 自带无线终端按键的搜索优先级。
