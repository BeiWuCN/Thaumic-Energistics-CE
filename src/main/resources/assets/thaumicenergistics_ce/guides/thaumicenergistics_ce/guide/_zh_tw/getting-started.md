# 入門

## 搭建小型網路

1. 打開魔導手冊，在應用能源學研究分支解鎖第一張源質元件和源質終端。
2. 將元件放入 <ItemLink id="ae2:drive" />，把驅動器接入已供能的 ME 網路。
3. 將 <ItemLink id="thaumicenergistics_ce:essentia_terminal" /> 安裝在同一網路的線纜上。
4. 打開終端，用裝有源質的安瓿存入源質，再用空容器取出。

終端離線時先檢查供能與頻道。若終端在線卻存不進某種源質，請檢查元件的容量和[分區](essentia-storage.md)。
