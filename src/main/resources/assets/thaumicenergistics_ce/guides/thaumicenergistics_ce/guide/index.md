# Thaumic Energistics: CE Guide

## About this guide

This guide collects every research entry of Thaumic Energistics: CE, organised along the same chapters as the Thaumonomicon. Each entry keeps the original wording from the manual so it can be read from the ME side at any time.

## Thaumonomicon chapters

Research in this mod unlocks through the Thaumaturge Thaumonomicon. The chapters below belong to the upstream manual; consult it there. They are prerequisites for the entries in this guide.

| Research | Thaumonomicon chapter |
| --- | --- |
| Base Energistics / Digitised Essentia | `thaumicenergistics_ce:base_energistics` |
| Essentia Storage / Essentia Terminal | `thaumicenergistics_ce:essentia_storage_1k` |
| Arcane Crafting / Knowledge Core | `thaumicenergistics_ce:arcane_terminal` |
