# Essentia Terminal

Digitised essentia cannot be seen or smelled. There ought to be somewhere to check how much remains.

## Step 1

I compared the terminal readings with each jar until I could account for the network's essentia. With a vessel connected, the amount withdrawn agreed as well. The §lEssentia Terminal§r is ready for regular use.

Watching the display all day is less appealing. I connected an §lEssentia Level Emitter§r, chose an aspect and quantity, and had it signal when the supply rose above or fell below that amount. A distillation setup can use that signal to start or stop.

## Step 2

I set an AE2 §lME Storage Monitor§r beside the equipment. There is no need for a separate essentia monitor: with it unlocked, a right-click with a labelled jar, phial or label selects the aspect to display.

The jar stays in my hand, its contents untouched. The screen reads the network's stock instead. I withdrew some essentia at the terminal and watched the number fall; returning it brought the reading back up.

A right-click with a wrench locks or unlocks the selection. While unlocked, an empty-hand right-click clears it. Now I can check the supply from the workbench without opening a terminal.
