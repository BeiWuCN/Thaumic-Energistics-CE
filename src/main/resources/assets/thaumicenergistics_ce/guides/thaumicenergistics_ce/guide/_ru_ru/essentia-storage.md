# Хранение эссенции

Ячейка хранит эссенцию напрямую. Наполненный флакон остаётся предметом. Чтобы поместить его содержимое в ячейку, внесите эссенцию через устройство, которое умеет с ней работать.

## Ёмкость и разметка

Обычные ячейки бывают от 1k до 256k. При установленном MEGA Cells доступны ячейки от 1M до 256M. Используйте <ItemLink id="thaumicenergistics_ce:essentia_cell_workbench" />, чтобы выбрать допустимые аспекты.

- Нажмите на слот разметки с флаконом одного аспекта на курсоре. Слот запомнит аспект, а флакон останется у вас.
- Нажатие с пустым курсором очищает слот.
- Кнопка с шестерёнкой размечает ячейку по её содержимому.
- В режиме копирования верстак сохраняет разметку после извлечения ячейки. При установке следующей ячейки её прежняя разметка будет заменена.
