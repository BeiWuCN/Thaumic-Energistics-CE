# 神秘水晶

神秘水晶用於製作電路板、處理器和工具。查閱魔導手冊中的注魔配方，把賽特斯石英母岩轉為神秘水晶母岩。

讓母岩各面留有空間，以便晶簇生長。把 <ItemLink id="ae2:growth_accelerator" /> 貼在母岩旁可加速生長。收穫後可將水晶加工成電路板，或拿來升級裝備。
