# 源质存储

源质元件直接存储源质。装满的安瓿仍是物品，可以放入物品存储。要把瓶内的源质存进源质元件，请通过支持源质的设备倒入网络。

## 容量与分区

常规元件从 1k 到 256k。安装 MEGA Cells 后，还可解锁 1M 到 256M 的元件。在 <ItemLink id="thaumicenergistics_ce:essentia_cell_workbench" /> 中，可以指定元件接收哪些源质。

- 拿着只装有一种源质的安瓿点击分区槽，可标记瓶内的源质。安瓿仍留在光标上。
- 空手点击可清除该格的标记。
- 点击齿轮按钮，可按元件现有库存分区。
- 开启复制模式后，取出元件时工作台会保留分区。插入下一张元件会覆盖它原有的分区。
