# 神秘能源：CE 指南

## 关于这本指南

本指南收录神秘能源：CE 的全部研究记录，按魔导手册中的同一批篇章整理。每条研究都保留了手册里的原文，方便在 ME 网络这一侧随时查阅。

本模组的研究以 Thaumaturge 的魔导手册为准解锁。下列篇章属于上游手册，请在魔导手册中查阅；它们也是本模组研究的 前置研究。
