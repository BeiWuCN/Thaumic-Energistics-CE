# 神秘水晶

神秘水晶可制成电路板、处理器和工具。魔导手册中的注魔配方会告诉你如何将赛特斯石英母岩转化为神秘水晶母岩。

给母岩各面留出空间，以便晶簇生长。将 <ItemLink id="ae2:growth_accelerator" /> 紧贴母岩放置可以加速。收获水晶后，可加工成电路板，也可用于升级装备。
