# 蒸餾樣板

處理樣板要把源質記為產物時，使用 <ItemLink id="thaumicenergistics_ce:distillation_encoder" />。

1. 放入空白樣板。
2. 設定原料。可以從 JEI 將物品拖到原料槽，這不會消耗物品。
3. 核對要素種類與數量，按蒸餾裝置能送回的實際產量編碼。
4. 將樣板放入相容的樣板供應器，並讓產出的源質回到 ME 儲存。

樣板告訴 ME 要等哪些產物。若爐子已完成加工但合成任務還在等，對照樣板記錄與實際回到網路的源質。
