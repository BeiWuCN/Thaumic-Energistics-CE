# Getting Started

## Build a Small Network

1. Open the Thaumonomicon and follow the Applied Energistics research branch to unlock your first essentia cell and terminal.
2. Install the cell in an <ItemLink id="ae2:drive" /> connected to a powered ME network.
3. Attach an <ItemLink id="thaumicenergistics_ce:essentia_terminal" /> to a cable on that network.
4. Open the terminal and deposit essentia from a filled phial. Use an empty container to withdraw essentia.

If the terminal is offline, check power and channels first. If it is online but cannot accept a particular aspect, check the cell's free capacity and [partition](essentia-storage.md).
