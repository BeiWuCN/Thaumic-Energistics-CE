# 入门

## 搭建小型网络

1. 打开魔导手册，在应用能源学研究分支解锁第一张源质元件和源质终端。
2. 将元件装入 <ItemLink id="ae2:drive" />，并把驱动器接入已供能的 ME 网络。
3. 把 <ItemLink id="thaumicenergistics_ce:essentia_terminal" /> 装到同一网络的线缆上。
4. 打开终端，用装有源质的安瓿存入源质，再用空容器取出。

终端离线时，先检查供能和频道。若终端在线却存不进某种源质，检查元件的剩余容量和[分区](essentia-storage.md)。
