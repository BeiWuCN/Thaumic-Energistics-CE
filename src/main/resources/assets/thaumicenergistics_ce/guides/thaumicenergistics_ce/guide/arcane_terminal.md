# Arcane Crafting Terminal

The workbench can draw its materials from the network and return the finished item to storage. There is no longer a reason to walk between two benches.

## Step 1

Half a recipe is forever sitting on the arcane workbench while the missing piece is in the network. I have tried joining the workbench to a terminal so that recipe and stock can be seen together.

With the materials arranged, the wand still recognises the recipe. There is room left for armour slots, which should spare me putting a whole set into my pack each time I change.

Craft this terminal from an AE2 ME Terminal, crafting table, thaumium, salis mundus and a thaumic circuit board. An essentia terminal is no longer required.

## Step 2

Place ingredients, crystals and a wand in the terminal. The block terminal draws VIS from its own chunk. The wireless terminal keeps its ingredients and upgrades locally and draws VIS from the player's chunk. Magic access cards can bind relay outputs for wand charging. Essentia access in arcane terminals is disabled by default and requires the configured option plus an essentia access card.
