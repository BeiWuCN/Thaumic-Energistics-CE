# Essentia Terminals

Use an <ItemLink id="thaumicenergistics_ce:essentia_terminal" /> to browse the aspects in your network. The search field accepts localized aspect names when Thaumaturge supplies a translation for the selected language.

A <ItemLink id="thaumicenergistics_ce:wireless_essentia_terminal" /> gives you the same view away from the cable. Link it to the network and check its charge and range if it will not open.

An <ItemLink id="thaumicenergistics_ce:essentia_level_emitter" /> can turn an essentia stock level into a redstone signal. Use it to let a machine know when you have enough of a particular aspect.

## Scanning Stored Items

Pick up a Thaumometer with the cursor and hover over one stored item in a compatible ME terminal. It uses the same discovery rules as scanning a slot in your inventory. A craftable entry with no stock cannot be scanned.
