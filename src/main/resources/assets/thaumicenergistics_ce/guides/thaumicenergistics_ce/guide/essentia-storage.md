# Essentia Storage

An essentia cell stores aspects directly. A filled phial is still an item and belongs in item storage unless you empty it through an essentia-capable device.

## Capacity and Partitioning

Standard cells range from 1k through 256k. When MEGA Cells is installed, additional tiers range from 1M through 256M. Use an <ItemLink id="thaumicenergistics_ce:essentia_cell_workbench" /> to set which aspects a cell accepts.

- Click a partition slot with a single-aspect phial to mark its contents. The phial stays on the cursor.
- Click with an empty cursor to clear that slot.
- Use the gear button to partition by the cell's current contents.
- Turn on copy mode to keep the partition when you remove the cell. Inserting another cell then overwrites its previous partition.
