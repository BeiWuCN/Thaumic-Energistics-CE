# Шаблоны дистилляции

Используйте <ItemLink id="thaumicenergistics_ce:distillation_encoder" />, если шаблон обработки должен указывать эссенцию как результат.

1. Вставьте пустой шаблон.
2. Укажите сырьё. Его можно перетащить из JEI в слот без расходования предмета.
3. Проверьте аспекты и количества. Запишите тот выход, который установка действительно вернёт в сеть.
4. Поместите шаблон в совместимый поставщик шаблонов и настройте возврат эссенции в МЭ-хранилище.

Шаблон определяет, каких результатов ждёт МЭ-сеть. Если обработка закончилась, а задание всё ещё выполняется, сравните запись в шаблоне с эссенцией, фактически поступившей в сеть.
