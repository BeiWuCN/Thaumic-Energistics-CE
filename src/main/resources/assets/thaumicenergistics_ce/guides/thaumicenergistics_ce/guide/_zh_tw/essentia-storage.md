# 源質儲存

源質元件直接儲存源質。裝滿的安瓿仍是物品，可放入物品儲存。要儲存瓶內的源質，請透過支援源質的設備將它倒入 ME 網路。

## 容量與分區

常規元件從 1k 到 256k。安裝 MEGA Cells 後可解鎖 1M 至 256M 元件。用 <ItemLink id="thaumicenergistics_ce:essentia_cell_workbench" /> 設定元件可接收的源質。

- 拿著只裝有一種源質的安瓿點擊分區槽，可標記瓶內的源質；安瓿仍留在游標上。
- 游標上沒有物品時，點擊分區槽即可清除該格。
- 點擊齒輪按鈕，可按現有庫存分區。
- 開啟複製模式後，取出元件時會保留分區。插入下一張元件會覆寫它原有的分區。
